# ⚔️ Wowhead Simple Parser & SQL Generator

Простой и удобный веб-интерфейс на базе [Streamlit](https://streamlit.io/) для быстрого парсинга данных с Wowhead и генерации готовых SQL-запросов для эмуляторов World of Warcraft (таких как **TrinityCore**, **AzerothCore** и др.).

## 🌟 Основные возможности

Парсер извлекает данные напрямую с Wowhead (поддерживаются версии **Retail, WotLK, Cataclysm, Classic Era**) и автоматически формирует чистый SQL-код.

Поддерживаемые модули:
*   🗡️ **Предметы (Items):** Базовые характеристики, качество, уровни. Генерирует `item_template`.
*   👾 **NPC (Существа):** Здоровье, мана, ранг, модель (DisplayID) и полный парсинг таблицы лута (Drop). Генерирует `creature_template` и `creature_loot_template`.
*   📦 **Объекты (Game Objects):** Парсинг содержимого (сундуки, руда, трава). Генерирует `gameobject_loot_template`.
*   💰 **Вендоры (Vendors):** Список продаваемых товаров и их цены. Генерирует `npc_vendor`.
*   ✨ **Тренеры (Trainers):** Список способностей и рецептов для обучения. Генерирует `npc_trainer`.
*   📜 **Квесты (Quests):** Тексты (описание, цели, завершение), требования, цепочки (пред/след), а также награды (золото, опыт, предметы на выбор). Генерирует `quest_template` и `quest_template_addon`.
*   🗺️ **Зоны (Zones):** Выгрузка полного списка NPC, обитающих в локации.
*   🏆 **Ачивки (Achievements):** Парсинг критериев и наград (звания, предметы). Генерирует шаблоны для `achievement_criteria_data` и `achievement_reward`.

## ⚙️ Особенности
*   **Автоопределение версии:** Скрипт сам найдет нужную базу данных (Retail/WotLK/Classic), если предмет или NPC отсутствует в актуальной версии.
*   **Мультиязычность:** Поддержка поиска на русском (`ru.wowhead.com`) и английском (`www.wowhead.com`) языках.
*   **Экспорт:** Возможность выгрузить сырые данные в JSON или скачать готовые `.sql` файлы в один клик.
*   **Прокси:** Встроенная поддержка прокси для обхода региональных или IP блокировок со стороны Wowhead.
